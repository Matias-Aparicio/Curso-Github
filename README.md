# Proyecto Web: Landing Page de Servicios
Este es un proyecto de desarrollo web que integra una estructura semántica en HTML5, 
estilos modernos con CSS3, y un diseño totalmente responsivo.

## Características:
- **Estructura Semántica**: Uso de header, nav, main, section y footer.
- **Flexbox**: Utilizado para la sección de productos (Cards).
- **CSS Grid**: Utilizado para la sección de reseñas de clientes.
- **Formulario Funcional**: Conexión con Formspree.
- **Google Fonts**: Integración de fuentes externas para tipografía moderna.
